# IELTS Daily Study Routine

লগইন ছাড়াই ব্যবহার করা যায়। কোনো সার্ভার বা অতিরিক্ত ফাইল প্রয়োজন নেই।

## GitHub Pages-এ চালু করার নিয়ম
1. ZIP খুলে `index.html` এবং `README.md` repository-এর মূল জায়গায় আপলোড করুন।
2. Settings → Pages → Deploy from a branch নির্বাচন করুন।
3. `main` branch এবং `/ (root)` নির্বাচন করে Save দিন।
4. GitHub Pages-এর দেওয়া লিংক খুলুন।

অগ্রগতি একই ডিভাইসের একই ব্রাউজারে অটোসেভ হয়। লগইন বা মোবাইল ও পিসির মধ্যে অগ্রগতি সিঙ্ক নেই। ব্রাউজারের সাইট ডেটা মুছে ফেললে সংরক্ষিত অগ্রগতিও মুছে যাবে।
